# 🐾 Pet Name Generator Web App

A simple web application that generates cute pet name suggestions based on pet type, gender, and personality. Built using **Flask** (Python backend) and **HTML/CSS/JavaScript** (frontend).

---

## 🚀 Features

- Choose pet type: Dog or Cat 🐶🐱  
- Choose gender: Male or Female ♂️♀️  
- Choose personality: Playful or Calm 😄😌  
- Get a list of suggested names instantly  
- Clean and responsive UI  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **Data Handling:** Fetch API and JSON
